# Icchē Neer Homestay
GitHub Pages static website inspired by the supplied Homestays of India screenshot.

Upload:
- index.html
- assets/style.css
- assets/app.js

Keep index.html in the repository root and assets as a folder.

Repository `icche-neer-homestay` URL:
https://sayansamanta88.github.io/icche-neer-homestay/

The page uses free Unsplash image URLs as temporary images. Replace them with your real Icchē Neer photographs before launch.

The booking form is static. GitHub Pages cannot send email by itself; connect it to Formspree/Web3Forms or a serverless backend when you are ready.


## Temporary images
This version uses remote Unsplash image URLs directly in index.html so no local image files are required. Replace the image URLs later with your actual Icchē Neer photographs.
